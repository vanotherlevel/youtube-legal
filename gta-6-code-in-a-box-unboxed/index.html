GTA 6's 'Code in a Box' Has Been Unboxed: No Disc, Just a Code and a Poster

By vAnother Level · Updated 2026-11-09
Home › GTA 6 Guides

The first customer has opened a GTA 6 "physical" copy, and there's no disc inside. As Rockstar confirmed earlier this year, the boxed PS5 edition of GTA 6 contains a download code instead of a disc. According to the unboxing shared from GTAForums, the box also has a double-sided poster.

Grand Theft Auto VI 'Code in a box' has finally been unboxed by an actual customer. As per reported already, it includes a double sided poster

— ben (@videotech) November 9, 2026
No disc at launch: confirmed by Rockstar. Poster: reported from the unboxing

What you need to know

  • No disc: you redeem the code on PlayStation Store and download the game (up to 212 GB).
  • Region-locked on PS5: the code works only in the region it was sold for, so imported copies may not work.
  • Can't resell it like a disc: once the code is redeemed, the box is just a box.
  • Preloads: codes from boxed copies come later than digital pre-orders, so check the PS5 preload fix if yours won't start.

Then vs now

In 2013, GTA 5 on Xbox 360 came on two discs with a printed map of Los Santos inside. In 2026, the biggest game of the year comes as a code and a poster. A disc version may follow later, but that's only a rumor for now.

Frequently asked questions

Does GTA 6 physical come with a disc?

No. At launch the boxed PS5 edition contains a download code, which Rockstar confirmed.

Is the GTA 6 PS5 code region-locked?

Yes, reports say PS5 codes only work in the region they were sold for.

What's inside the GTA 6 box?

A download code and, according to the first customer unboxing, a double-sided poster.
