GTA 6 Needs PS5 Update 14.23: Install It Before Midnight

If you're playing GTA 6 on PS5, install system software 26.07-14.23.00 before launch. Sony started rolling it out on November 17, 2026, and PlayStation Support reportedly told players to download it before midnight on November 19, when GTA 6 unlocks.

REPORTED: PlayStation Support US on X, via Android Authority

The update is small, around 1.2 to 1.3 GB, so do it now instead of at 11:59 PM, when millions of consoles will be hitting PlayStation Network at once.

It comes about two weeks after 26.07-14.22.00 (November 2), which also only listed security fixes. Sony hasn't said why GTA 6 needs this exact version.

THEORY

Push Square and MP1st link Sony's run of quick security patches to ongoing PS5 jailbreak attempts. Sony hasn't confirmed that, so treat it as a theory.

How to install PS5 update 14.23

  1. Open Settings from the PS5 home screen.
  2. Go to System → System Software.
  3. Pick System Software Update and Settings → Update System Software.
  4. Choose Update Using Internet. The console restarts to install it.
  5. To check it worked: Settings → System → System Software → Console Information. It should show 26.07-14.23.00 or newer.
Tip: also open the GTA 6 tile and press Options → Check for Update, so any day-one game patch is already on your console before midnight. Leave the PS5 in Rest Mode with internet on, and it will keep downloading.

Does this affect Xbox?

No. This is a PlayStation system update only. Xbox Series X|S players just need the pre-load finished. Xbox Cloud Gaming players can stream from 1 AM ET on November 19 (see our release time in every region page).

Frequently asked questions

Do I need a PS5 update to play GTA 6?

Reportedly yes. PlayStation Support told players to download system software 26.07-14.23.00 before midnight on November 19, 2026.

How big is PS5 update 14.23?

About 1.2 to 1.3 GB, according to Push Square and MP1st.

What does PS5 update 14.23 change?

Sony's patch notes only say it includes security fixes to the system software. There are no GTA 6 features in it.

Does Xbox need an update for GTA 6?

No system update has been announced for Xbox. Just finish the GTA 6 pre-load.
