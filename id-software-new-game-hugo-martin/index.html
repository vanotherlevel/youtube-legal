id Software Confirms Its Next Game, Directed by Doom's Hugo Martin

By vAnother Level · Updated 2026-11-12
Home › id Software

The Doom studio has its next game. Xbox CEO Asha Sharma confirmed at Xbox FanFest that id Software is "already working on its next game", and id followed up with who's leading it.

We're incredibly excited about our next project, a new game from our teams in Texas and Frankfurt, with game direction once again by Hugo Martin.

— @idSoftware 2026-11-12
Confirmed by id Software, November 12, 2026

It's early. id says "it'll be some time before we're ready to share more". The news follows layoffs at Xbox that VGC reports hit id Software hard; separately, a group of former id developers formed a new studio, Hidden Horses.

Then vs now

Hugo Martin joined id in 2013 and led Doom (2016), Doom Eternal and Doom: The Dark Ages. id hasn't said whether the new game is Doom, Quake or something new.

Source: id Software and Xbox, reported by VGC. Watch more on our YouTube channel: vAnother Level.
